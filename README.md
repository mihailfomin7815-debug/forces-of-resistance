## Описание проекта

Интерактивная анимация движения частиц разного размера через две среды с различными физическими свойствами.

Частицы движутся под действием силы тяжести и испытывают сопротивление среды. При пересечении границы сред сила сопротивления изменяется в зависимости от плотности и вязкости среды, размера и скорости частицы.

Модель учитывает инерцию частиц, зависящую от их массы.

## Реализуемые возможности

- Отображение двух сред с горизонтальной границей.
- Анимация частиц разных размеров.
- Одинаковая начальная вертикальная скорость частиц.
- Моделирование силы сопротивления в зависимости от размера частицы.
- Учёт массы и инерции частиц.
- Изменение скорости частиц при переходе между средами.
- Графический интерфейс на Tkinter.
- Управление анимацией с помощью кнопок «Старт» и «Сброс».

Для запуска автоматических тестов выполните команду:

```bash

```

## Обоснование структуры проекта

Код разделён на несколько модулей для удобства разработки и сопровождения.

- `main.py` — точка входа в приложение.
- `src/app.py` — создание окна и управление анимацией.
- `src/models/` — физическая модель частиц и математические вычисления.
- `src/renderers/` — отрисовка частиц и границ сред.
- `src/widgets/` — элементы управления интерфейсом.
- `tests/` — автоматические тесты физической модели.

Такое разделение позволяет отдельно изменять физику, графическое отображение и интерфейс.
